# Event ke baad ka flow (v2_dev, deploy baaki)

| Kab | Kya hota hai |
|---|---|
| Event khatam | Thank-you card + thank-you push |
| Ek baar (organizer jab link daale) | **Memories** push: photo album / WordPress.tv speaker sessions; `/event/{slug}/memories` page archive ke baad bhi khulta hai |
| **Day 7** | Push: "keep your WordCamp" |
| **Day 15** | Push: "take it with you" — sirf **agla WordCamp** dikhta hai, aur sirf us phone par jisme profile ya mile hue log hon |
| Roz | `campbuddy:upcoming-push` — agle WordCamp ka push |
| **30 din tak** | Find / move / bring data khula (pehle 7 din tha). Phir personal data mitta hai |
| 3 mahine | Event picker par "Completed" card (Memories ke saath) |

**"Pichhle WordCamp se laao":** naye event par profile ke jawab aur mile hue log phone par laa sakte ho (`bring-data.js`, `move-data.js`).
