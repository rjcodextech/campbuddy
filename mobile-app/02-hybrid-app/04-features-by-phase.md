# Features — phase wise

## Phase 1 — MVP
1. Capacitor shell, splash, icon, status bar.
2. Live site WebView + offline screen + external links browser mein.
3. **Session reminders = local notifications** (save par schedule, unsave par cancel, 10 min pehle). Permission pehle save ke baad, deny hamesha maano (N1/N4).
4. **Deep links:** `/event/...`, `/event/{slug}/memories` — App Links / Universal Links.
5. Camp Card + PDF: save + Share sheet.
6. Install / iPhone-notice UI chhupana; GA `platform`.
7. Android back = page back.
8. **Discovery report + block** (Apple 1.2).

## Phase 2 — Retention
1. **FCM:** thank-you, Memories, day 7, day 15, upcoming, discovery wave.
2. Notification tap → sahi page.
3. App badge, haptics, in-app review prompt (ek baar).

## Phase 3 — Polish (data dekh ke)
Home screen widget, native calendar, bundled shell, Apple/Google Wallet pass.

**Bahar:** login, QR scan se contact list, dark mode (standing faisle).
