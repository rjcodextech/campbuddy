# 14. Fallback plan

[← Back to index](../SKILL.md) · Previous: [13. Pre-launch blockers](13-prelaunch-blockers.md) · Next: [15. Testing →](15-testing.md)

V1 remains fully functional and deployable independently. If any of [13](13-prelaunch-blockers.md)'s blockers can't close in time, or the Laravel rewrite hits a wall before launch, **V1 ships instead of an unfinished V2** — a live decision point to revisit a few days out, not a theoretical option. V2 continuing past the event date has no deadline pressure either way.
