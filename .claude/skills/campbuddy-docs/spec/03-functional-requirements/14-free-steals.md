# 3.14 Free Steals (Explore → Free Steals, 29 Sep 2026)

[← Index](00-index.md) · Previous: [3.13 Data controls](13-data-controls.md) · Back to: [Spec index](../../SKILL.md)

**Deals help you save money on paid things. Free Steals help you discover great things that are already free.**

A small, hand-picked shelf of WordPress plugins and tools that cost nothing: developer tools, Gutenberg utilities, WooCommerce, AI, performance, security. It is not a plugin directory. The aim is that an attendee opens it and thinks "I didn't know this existed". Makers are mixed on purpose: a tool from Automattic sits beside one from Lubus, Multidots, rtCamp, Gaurav Tiwari, Nitin Prakash, Abhishek Deshpande or Hardeep Asrani, because small community makers don't have marketing teams and CampBuddy can help people find them.

## How it works

- **One list for every event.** Table `free_steals` (no `event_id`): `name`, `description` (≤300), `maker`, `category`, `url`, `cta_label` (empty = "Get it free"), `is_featured`, `is_active`, `sort_order`. Model `App\Models\FreeSteal`.
- **Curated, not a directory.** The collection can be bigger (15–30), but attendees see only the first `FreeSteal::SHOWN` (12) switched-on ones by `sort_order` (`FreeSteal::shown()`).
- **Featured** (gold tag on the card) = the CampBuddy team finds it especially worth a look. Never paid placement, never "most popular".
- **Card** (`attendee/partials/free-steal-card.blade.php`) reuses the deal card's styles (`.deal-card`, `components/_sponsor.scss`): a line icon picked from the category's first known word (`FreeSteal::icon()`: AI → sparkles, Gutenberg → columns, Security → id-card, Performance → zap, Media → camera, Local Development → laptop, Content/Publishing → pen-tool, WooCommerce → tag, Developer Tools/Utilities → wrench; otherwise sparkles), name, "by maker", Featured tag, description, category, and one button.
- **The link opens in a new tab** (`target=_blank rel="noopener"`, plain link, no in-app browser): GitHub and WordPress.org refuse to be framed.
- **Tab** sits between Deals and Info; `?tab=free-steals` deep-links to it. Explore's tabs are five equal cells with a line icon over a short label (`.tab-strip--icons`, `components/_misc.scss`: People · Sponsors · Deals · Free Steals · Info — "Event Info" became "Info", so the browser title reads "Info | Explore | …"), so all five fit a phone without sideways scroll; My Day keeps the plain `.tab-strip`. The switch is the existing generic `explore.js` code; `explore_tab_view` reports `tab: free-steals`.
- **Analytics.** "Get it free" reports `free_steal_open` (declarative `data-track`) with `offer_title` = the steal's name and `link_domain` — GA4's 50 custom dimensions are all used, so the deal-title dimension is reused. A sent suggestion reports `free_steal_suggest` with no params.
- **Made by someone at this WordCamp.** `free_steals.maker_links` (one per line: WordPress.org profile, GitHub, X, LinkedIn, website). `FreeSteal::forEvent($event)` matches them against that event's non-suppressed roster links (`normalizeLink`: lower-case, no scheme/`www.`/query/trailing slash, `x.com` = `twitter.com`; whole address only, never a prefix), sets `made_here`, and puts those cards first with a peach "Made by someone at this WordCamp" pill. Cached 10 minutes per event, keyed on the steals' `updated_at` so an admin edit counts at once. Only ~4% of roster entries carry a WordPress.org link, hence the other link kinds. Shipped steals have no maker links; an admin adds them.
- **Suggest a Free Steal.** A dashed box under the list opens a dialog (`attendee/templates/free-steals.blade.php`, `free-steal-suggest.js`): tool name + link required ("github.com/x" gets `https://`), maker, why (≤300), email (optional). `POST /api/v1/events/{slug}/free-steal-suggestions` (`Api\FreeStealSuggestionController`, `throttle:api-writes`) stores it in `free_steal_suggestions` for review — never shown to attendees. A filled hidden `website` field (bot trap), a repeat of the same link from the same event, or more than `FreeStealSuggestion::MAX_WAITING` (300) waiting are answered 201 and not stored.
- **Admin → Free Steals** (`Admin\FreeStealController`, `/admin/free-steals`, super-admin area only): "Suggestions from the app" first (Add = the form pre-filled from it, and saving deletes the suggestion; Dismiss), then the list with Showing / "On, but past the first 12" / Off badges, add, edit (incl. maker links), remove. Links must be `http(s)`.
- **Shipped list.** Migration `2026_10_05_090100_install_free_steals` writes out all 16 rows, every field (`steals()`, from `mockups/campbuddy-free-steals.csv`, links checked on the web 29 Sep) and runs `App\Support\FreeSteals::install(array)` (skipped in unit tests). Blocks Export Import links to `wordpress.org/plugins/blocks-export-import/` (the CSV had the whole Otter Blocks repo); The Off Switch's `wp-avoid-slow` slug is right (the plugin was renamed). **Maker links** ship too: individuals — WordPress.org, GitHub, website, X (Gaurav `gauravtiwari`/`wpgaurav`, Abhishek `deshabhishek007`/`fitehal`, Nitin `nitin247`/`nitinprakash`, Hardeep `hardeepasrani`/`HardeepAsrani`); companies (Lubus, Multidots, rtCamp, Automattic) — WordPress.org and GitHub only, since their website is on many employees' profiles. `maker_links` is created with the table; `2026_10_05_090400_complete_installed_free_steals` fixes a database installed before the data was finished (Otter link → plugin page, empty maker links filled from `steals()`, admin edits kept). the 12 marked "Initial 12" switched on, the other 4 switched off. **Tools made by individuals are shown first** (owner's call, 29 Sep): WordPress Skills (Gaurav Tiwari), The Off Switch (Abhishek Deshpande), Thank You Page for WooCommerce (Nitin Prakash), Blocks Export Import (Hardeep Asrani), then the companies' (Lubus, Multidots, Automattic, rtCamp). 4 Featured: WordPress Skills, The Off Switch, Visual Blueprint Builder, Multidots Passkey Login. Idempotent, matched on link; never overwrites an admin's edits.
- **Freshness.** `DataVersion` includes the Free Steals (`max(updated_at)#count`), and every admin add/edit/remove forgets it for approved and active events, so open apps reload at their next check. The deploy that added this changed every event's fingerprint once.

Tests: `tests/Feature/FreeStealsTest.php`, `tests/js/free-steal-suggest.test.mjs`.
