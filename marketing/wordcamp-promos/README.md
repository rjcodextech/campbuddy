## Har event folder mein

```
<event>/
  mp4/          3 final reels (1080×1920, 30 fps, H.264 + AAC)
  srt/          subtitles (YouTube / LinkedIn pe upload karne ke liye)
  posts/reel-N/ posts.md (LinkedIn, X, Instagram, YouTube copy) + images/ (8 platform sizes)
  scripts.md    scene-by-scene timing, caption, voice
  reels.html    browser preview (same player as promo-reels/campbuddy-reels.html)
  screens/      CampBuddy screens with that event's real public data
  audio/        reel audio used for the videos
```
