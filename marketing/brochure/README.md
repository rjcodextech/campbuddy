# CampBuddy brochure (1 page)

A4 flyer, QR code ke saath. Stall, registration desk ya notice board ke liye.

| | |
|---|---|
| Printer ke liye | **`print/CampBuddy-brochure-A4.pdf`** |
| Size | A4, 210 × 297 mm, har taraf **3 mm bleed** (file 216 × 303 mm) |
| PNG | `print/CampBuddy-brochure-A4.png`, **900 dpi** |
| QR | `https://campbuddy.club/?utm_source=brochure&utm_medium=print` (GA mein source "brochure") |

Printer ko batayein: colours RGB mein hain; pehle ek sample print dekh lein.

Badalna ho to `brochure.html` edit karke chalayein: `node marketing/brochure/render.mjs`. Phone screens `public/media/tour/` se aati hain.
