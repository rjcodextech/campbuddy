### Recording / AI-voice tips

- Har reel ka `.srt` file seedha ElevenLabs, Descript, CapCut jaise tools mein import ho jaata hai — wo lines ko exact timestamp par sync kar denge.
- Agar tool `.srt` nahi leta, upar ki table ke Start/End (mm:ss.ms) se manually clip timing set kar sakte ho.
- Scene 0.3–0.5s ka "rise-in" caption animation leta hai — voice thoda sa (100–200ms) baad shuru karoge to caption ke saath naturally lagega.
- MP4s silent hain — AI voice generate karke isi timestamp ke saath ek naya audio track mux kar do (ffmpeg: `ffmpeg -i video.mp4 -i voice.mp3 -c:v copy -c:a aac -shortest out.mp4`).
