# CampBuddy Unified Icon Design System

Complete icon set designed for CampBuddy Web App, Admin Panel, and Compose Multiplatform Mobile APK.

* **Total Icons:** 76
* **Formats Provided:** Standalone SVG (`docs/icons/svg/*.svg`) and 512×512 High-Res Transparent PNG (`docs/icons/png/*.png`)
* **Design Language:** Consistent 24×24 viewport, 1.8px optical stroke weight, rounded caps/joins (`stroke-linecap="round"`, `stroke-linejoin="round"`), CampBuddy Navy `#1E293B` default tint.
* **Interactive Specimen:** View `docs/icons/index.html` in any browser to inspect and copy assets.

## Pipeline Automation

* **PHP Source of Truth:** `app/Support/LineIcons.php`
* **Compile to Native Kotlin Multiplatform:**
  ```bash
  php artisan campbuddy:app-icons
  ```
* **Verify Synchronization:**
  ```bash
  php artisan campbuddy:app-icons --check
  ```
* **Re-export Documentation Assets:**
  ```bash
  node tools/export-all-icons.mjs
  ```
